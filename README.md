The official and private platform powering the exclusive LNY software suite.

## Overview
LNY-App serves as the development hub for all applications under the LNY Ecosystem. Inspired by the elegance and prestige of Vertu, every app is crafted with luxury, exclusivity, and power in mind.

### Key Applications

- **LNY GPT** – Private Vietnamese-language AI assistant for the Admin.
- **LNY Cloud** – Secure cloud storage with ultra-fast performance and zero device limitations.
- **LNY Mail** – Email system with @lny.com domain for admin and @lnymail.com for users.
- **LNY Cloud Phone** – Virtual smartphone environment: Oppo Find X7 Ultra for users, Vertu Iron Flip for Admin.
- **LNY PLAY** – Game world inspired by Play Together. Admin has unlimited access & custom character.
- **LNY Search** – LNY’s private search engine platform.
- **LNY Authenticator** – Official 2FA tool across the LNY ecosystem.
- **LNY Weather** – Earthquake and weather forecasting tool with full access for Admin.
